The question is whether chance alone plausibly explains it.

The two hypotheses

Written before any data is collected. Always.

H0: μ = 0
The drug does nothing. Any change we measure is luck.
Ha: μ ≠ 0
The drug changes blood pressure — in some direction, we are not saying which.

We never set out to prove Ha. We assume H0 and see whether the data makes it look ridiculous.

What α is really buying

α is not a fact about your data. It is a decision you made in advance about which mistake you would rather make.

Set α = 0.05 and you are saying: if this drug truly does nothing, I accept that one trial in twenty will still tell me it works. That is a Type I error — approving a useless drug. It is not a flaw in the method; it is the price you agreed to pay, written down before you looked.

Drop α to 0.01 and false approvals get rarer — but you now miss real drugs that a looser threshold would have caught. That is a Type II error, and in health it has a body count of its own. There is no setting of α that avoids both. You are choosing which patients to fail.

Notice also what the decision never says. When p is large we say “do not reject H0” — never “accept H0,” and never “the drug does nothing.” Failing to find evidence is not evidence of absence. A trial of ten patients fails to find almost everything.
